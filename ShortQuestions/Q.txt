2. Explain TLS, PKI, certificate, public key, private key, and signature.
TLS: Transport Layer security
A security protocol that encrypts data sent between browser and server.

PKI: Public Key Infrasturcture
A system that manages trust on the internet


Certificate:
A digital ID for web and server

Public Key:
A key that everyone can see

Private Key:
A secret key that used with public key together to verify requests.

Signature:
A way to prove authenticity and integrity of the data.

16. how to get value from application.properties in Spring security?
Use @Value:
@Value("${jwt.secret}")
private String secret;

Use @ConfigurationProperties:
@ConfigurationProperties(prefix = "jwt")
public class JwtConfig {
    private String secret;
}


17. What is the role of configure(HttpSecurity http) and configure(AuthenticationManagerBuilder auth)?
configure(HttpSecurity http):
http
  .authorizeHttpRequests()
  .requestMatchers("/admin").hasRole("ADMIN")
  .anyRequest().authenticated();

Controls:
- URL security
- CSRF
- Session policy
- Filters

configure(AuthenticationManagerBuilder auth):
auth
  .userDetailsService(userDetailsService)
  .passwordEncoder(passwordEncoder);

Controls:
- User source
- Password encoding
- Authentication providers
